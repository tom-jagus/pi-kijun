# Remove obsolete vault guidance

## Outcome

Remove Kijun's vault-specific instructions and routing because the user no
longer uses vault or Obsidian notes.

## Why

The user no longer uses Pi for personal vault notes. Keeping vault conventions,
a configured destination, and note-writing suggestions adds irrelevant context
and maintenance work.

## Boundaries

Remove vault-specific behaviour from the operating contract and skills, and
align the workflow guide. Preserve ordinary repository documentation guidance,
project records, and general editing, acceptance, and Git authority rules.
Do not replace vault guidance with a reference, skill, or manual journaling
workflow. Do not inspect, move, delete, or otherwise change actual vault notes,
configuration, attachments, or external tools. Preserve historical records.

## Acceptance criteria

- The operating contract and skills no longer configure a personal vault,
  route work to vault guidance, prescribe note conventions, or suggest vault
  updates as part of project work.
- The documentation skill remains focused on repository documentation, with
  its README conventions, factual checks, and timing and authority boundaries
  intact.
- The workflow guide no longer advertises vault support or describes obsolete
  vault-specific procedures.
- Removing vault-specific exceptions does not broaden automatic documentation
  maintenance beyond the relevant repository or weaken general edit,
  acceptance, or Git permissions.
- No replacement vault reference, note-taking workflow, or installation
  resource is introduced, and actual vault contents and configuration remain
  untouched.
- Manual journaling and note-taking remain rationale in project records only;
  the contract and skills do not mention the user's replacement habits or
  add instructions about them.

## Review

The user accepted the brief after review of its outcome criteria. Active
instructions and the workflow guide no longer contain vault procedures or a
replacement note-taking workflow. Repository documentation conventions and
edit, acceptance, and Git boundaries remain in the contract and skills.

External vault resources were not inspected. Their unchanged state relies on
session evidence, a limitation disclosed before acceptance.
