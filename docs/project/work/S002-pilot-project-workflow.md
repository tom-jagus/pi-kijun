# Pilot the project workflow

## Outcome

Check whether fresh sessions select the right activities and maintain readable
records without unnecessary planning or implementation.

## Acceptance criteria

These pilot criteria are proposed, not yet accepted.

- Brainstorming captures a brief without automatically producing slices.
- Refinement prepares selected slices without implementing them or expanding
  the project, and leaves unsettled work Draft.
- Development refuses Draft work and hands delivered work to Review, not Done.
- Review distinguishes satisfied, unmet, and unverified criteria and does not
  close a brief merely because its slices are complete.
- The user can read and edit the resulting records and judges them useful for
  continuing work without a long explanation.

## Tasks

- [ ] Exercise the activities and inspect their resulting records.
